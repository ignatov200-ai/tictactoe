# Публикация игры на GitHub Pages

Игра — одностраничное приложение без роутинга, поэтому GitHub Pages подходит
идеально. Деплой автоматизирован через GitHub Actions: после каждого пуша в `main`
сборка собирается и публикуется сама.

## Шаг 1. Залейте код на GitHub

```bash
git init
git add .
git commit -m "Крестики-нолики: игра для ВК"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

## Шаг 2. Включите Pages в настройках репозитория

1. Откройте репозиторий → **Settings** → **Pages**.
2. **Source** → выберите **GitHub Actions** (не «Deploy from a branch»).

Это всё. Workflow `.github/workflows/deploy.yml` запустится автоматически
и опубликует игру. Ссылка появится в Settings → Pages и в описании репозитория:

- `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Как это работает

- При пуше в `main` (или вручную через кнопку «Run workflow») GitHub:
  - ставит зависимости (`npm ci`),
  - собирает игру командой `npx vite build --base=./` — флаг `base=./`
    делает пути к ассетам относительными, чтобы игра работала и в корне,
    и в подкаталоге `/<репозиторий>/`,
  - кладёт папку `dist/` в артефакт и публикует её на Pages.

## Ручная публикация (без Actions)

Если хочется собрать и залить вручную:

```bash
npx vite build --base=./
npx gh-pages -d dist
```

(предварительно в Settings → Pages источником укажите ветку `gh-pages`)

## Игра вне ВКонтакте

Игра полностью работает и в обычном браузере: вызовы VK Bridge
(`VKWebAppInit`, получение имени) обёрнуты в try/catch и просто не срабатывают
вне клиента ВК — вместо имени «Привет, …» игра идёт без него.
Так что ссылка GitHub Pages сама по себе — уже играбельная версия.
