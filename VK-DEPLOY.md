# Публикация игры «Крестики-нолики» на хостинг ВКонтакте

VK предоставляет **бесплатный официальный хостинг** для мини-приложений.
Весь проект уже подготовлен: сборка складывается в `dist/`, конфигурация лежит в
`vk-hosting-config.json`, инструмент деплоя установлен в зависимостях.

---

## Шаг 1. Создайте мини-приложение в VK

1. Откройте портал разработчиков: **https://dev.vk.com** и войдите под своим аккаунтом ВК.
2. Перейдите в **«Мои приложения» → «Создать» → «Мини-приложение»**.
3. Укажите название (например, «Крестики-нолики») и создайте приложение.
4. На странице приложения скопируйте его **ID** (число в адресе, например `51628451`).

## Шаг 2. Получите приватный ключ хостинга

1. В настройках созданного приложения откройте раздел **«Хостинг»**.
2. Нажмите **«Сгенерировать ключ»** (или «Показать ключ») и скопируйте его.
   Ключ привязан к вашему аккаунту — никому его не передавайте.

## Шаг 3. Подставьте ID приложения

Откройте файл `vk-hosting-config.json` в корне проекта и замените `0` на ID из шага 1:

```json
{
  "static_path": "dist",
  "app_id": 51628451,
  ...
}
```

## Шаг 4. Соберите и загрузите игру

В терминале в корне проекта выполните:

```bash
npm run build          # соберёт игру в папку dist/
npx vk-miniapps-deploy # загрузит dist/ на хостинг VK
```

При первом запуске инструмент попросит **вставить приватный ключ** из шага 2 —
введите его и нажмите Enter. Затем согласитесь обновить URL размещения
(инструмент сам пропишет адреса хостинга в настройках приложения).

Готово! В конце вы увидите ссылку вида `https://<уникальный-адрес>.hosting.vk.com`.

## Шаг 5. Откройте игру в ВКонтакте

- Прямая ссылка для теста: `https://vk.com/app<ваш-ID>` (видна вам как разработчику).
- В настройках приложения (раздел «Размещение») можно добавить **иконку** и описание.
- Чтобы игру увидели все, отправьте приложение на **модерацию** в том же разделе —
  обычно проверка занимает до нескольких дней.

## Альтернатива: загрузка ZIP вручную

Если не хочется пользоваться командной строкой:

1. Выполните `npm run build`.
2. Запакуйте **содержимое** папки `dist/` (файлы `index.html` и `assets/`, не саму папку)
   в ZIP-архив.
3. В dev.vk.com → ваше приложение → раздел **«Хостинг»** → **«Загрузить архив»**.
4. Укажите точки входа `index.html` для web, мобильной и m.vk версий.

## Локальная отладка внутри ВК (по желанию)

Проверить игру в реальном клиенте ВК до публикации можно через VK Tunnel —
он пробрасывает локальный `npm run dev` на публичный HTTPS-адрес:

```bash
npx @vkontakte/vk-tunnel --insecure=1 --http-protocol=http --ws-protocol=wss --host=localhost --port=3000
```

Затем в dev.vk.com → «Настройки» → «Адреса» временно вставьте выданный туннелем URL.

### Что уже учтено в коде

- `VKWebAppInit` вызывается при старте — приложение корректно поднимается в iframe ВК.
- VK Bridge (имя пользователя для приветствия) встроен прямо в сборку — CDN не нужен.
- Все пути ассетов относительные к корню домена хостинга VK — работают «из коробки».
- Шрифты подгружаются с Google Fonts, HTTPS обеспечивает сам хостинг VK.
