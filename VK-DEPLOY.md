# Публикация игры на хостинге ВКонтакте

Игра готова к загрузке как **VK Mini App**: VK Bridge встроен в сборку
(`VKWebAppInit` вызывается при старте), приложение одностраничное,
без внешних зависимостей на рантайме.

## Шаг 1. Создайте мини-приложение

1. Откройте [dev.vk.com](https://dev.vk.com) и войдите под своим аккаунтом ВК.
2. «Мои приложения» → **Создать** → тип **«Мини-приложение»**.
3. Заполните название (например, «Крестики-нолики») — получите **ID приложения**.

## Шаг 2. Разрешите деплой и получите ключ

В настройках приложения:

1. Раздел **«Хостинг»** → включите **«Разрешить изменять настройки размещения»**.
2. Раздел **«Настройки» → «Секретный ключ» / «Приватный ключ»** → **Сгенерировать**.
   Скопируйте ключ — он показывается один раз.
3. В файле `vk-hosting-config.json` замените `"app_id": 0` на ваш ID.

## Шаг 3. Загрузите сборку

```bash
npm install
npm run build
npx vk-miniapps-deploy
```

При первом запуске утилита попросит вставить приватный ключ.
После загрузки адреса в настройках хостинга обновятся автоматически.

Игра откроется по ссылке: `https://vk.com/app<ваш-ID>`.

## Альтернатива: загрузить вручную

В разделе «Хостинг» на dev.vk.com есть ручная загрузка:
соберите ZIP из содержимого папки `dist/` (`index.html` + папка `assets/`
в корне архива) и перетащите его в окно загрузки.

## Локальная отладка внутри ВК

```bash
npm run dev
npx @vkontakte/vk-miniapps-tunnel
```

Туннель даст https-адрес, который можно временно указать в настройках
хостинга приложения — игра будет открываться прямо из ВКонтакте
с вашим локальным кодом.

## Публикация для всех

Когда всё проверено: «Управление» → **«Отправить на модерацию»**.
Черновник доступен вам и тестировщикам сразу после загрузки.
